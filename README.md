# Bit-Clip Lab data: Banjo-Tooie · N64 PAL

Data files for the [Bit-Clip Lab](https://kweber1.github.io/bitclip-lab/tooie/?v=pal) viewer (the viewer and the tools that make these files are in [kweber1/bitclip-lab](https://github.com/kweber1/bitclip-lab)). Each game version has its own repository so each gets its own 1 GB GitHub Pages site; the viewer loads from all of them on the same `kweber1.github.io` address.

Nothing here yet: the PAL census needs a PAL ROM and a check of PAL geometry and timing in BizHawk first.

Files end in `.wasm` so GitHub Pages serves the gzipped bytes as they are. No game art is published here.
